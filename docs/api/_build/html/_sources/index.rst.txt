Standard Library Modules
-------------------------

The Mellea standard library (``mellea.stdlib``) provides core components for generative programming:

* **chat** - Chat message handling and conversation management
* **functional** - Functional programming utilities for LLM operations
* **session** - Session management for stateful interactions
* **sampling** - Sampling strategies (best-of-n, majority voting, budget forcing)
* **rewards** - Reward models and scoring utilities
* **docs** - Document processing and rich document handling
* **reqlib** - Requirement libraries for validation (markdown, python, tools)
